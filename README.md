# DoseRAD2026 Photon Dose on CT Submission

Grand Challenge `invoke` container for the DoseRAD2026 Photon-on-CT task.

The repository contains only inference code. Model weights are intentionally
excluded from Git and are uploaded separately as `model.tar.gz`.

See [SUBMISSION_GUIDE_ZH.md](SUBMISSION_GUIDE_ZH.md) for the complete Chinese
build, upload, preliminary-test, and troubleshooting procedure.

For the shortest no-Docker workflow, see
[你需要做的事情_无需Docker.md](你需要做的事情_无需Docker.md).
